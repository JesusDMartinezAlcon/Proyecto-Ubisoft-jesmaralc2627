# Proyecto Ubisoft

Proyecto web sencillo que simula la página principal de Ubisoft.

## Descripción

La aplicación está formada por una única página HTML que contiene:

- Un menú de navegación con las opciones **Juegos**, **Tienda** y **Sobre nosotros**.
- Un título principal de Ubisoft.
- Un campo de búsqueda.
- Un botón para buscar videojuegos.

## Estructura del proyecto

El proyecto contiene los siguientes archivos:

- `index.html`: página principal de la aplicación.
- `README.md`: documentación básica del proyecto.

## Tecnologías utilizadas

- HTML5
- CSS mediante estilos en línea

## Ejecución

Para visualizar el proyecto, abre el archivo `index.html` con un navegador web.
