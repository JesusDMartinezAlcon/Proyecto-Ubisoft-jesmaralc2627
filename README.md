# Proyecto Ubisoft

Proyecto web educativo que reproduce de forma simplificada la página principal de Ubisoft.

> **Aviso:** este proyecto se ha realizado con fines exclusivamente didácticos y no tiene ninguna relación con Ubisoft Entertainment.

## Descripción

La aplicación está formada por una única página HTML que incluye:

- Un **menú de navegación** con las opciones *Juegos*, *Tienda* y *Sobre nosotros*.
- Un **encabezado principal** con el nombre de Ubisoft.
- Un **campo de búsqueda** de texto.
- Un **botón** para buscar videojuegos.

## Estructura del proyecto

```
proyecto-ubisoft/
├── index.html   # Página principal de la aplicación
├── README.md    # Documentación del proyecto
└── captura.png  # Captura de pantalla usada en este README
```

## Tecnologías utilizadas

| Tecnología | Uso |
|------------|-----|
| HTML5      | Estructura y contenido de la página |
| CSS        | Estilos aplicados en línea mediante el atributo `style` |

## Requisitos

Solo se necesita un navegador web actual (Chrome, Firefox, Edge…). No requiere instalación ni servidor.

## Posibles mejoras

- Mover los estilos en línea a una hoja de estilos externa (`styles.css`).
- Añadir funcionalidad real al buscador con JavaScript.
- Crear las páginas de *Juegos*, *Tienda* y *Sobre nosotros*.
- Adaptar el diseño a dispositivos móviles (diseño responsive).
